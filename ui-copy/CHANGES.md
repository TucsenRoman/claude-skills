# ui-copy changes

- 2026-10-08: Impeccable's clarify is now the main method (not an occasional mode), minus its accessibility and translation parts.
  Why: ui-copy had no source guide; clarify covers what the viseez copy pass actually found.
- 2026-10-08: Read whole flows; each state leads with the one fact, then the next action.
  Why: clarify's message hierarchy; viseez had states like future days saying "Nothing spent".
- 2026-10-08: Errors say what failed, why if known, what to do; no jokes around money, deletion or access.
  Why: viseez errors stopped at "Could not ..." with no next step.
- 2026-10-08: Kept ui-copy's own voice load, options for headers/CTAs, one wit per screen, phone-width fit; report in the fast y/n format.
  Why: clarify has none of these; the user wants quick decisions.
- 2026-10-08: Added a terminology glossary step (kept in the project's design doc).
  Why: most viseez copy fixes were the same idea worded differently (log in/sign in, reconnect/re-link, connect/link).
- 2026-10-08: Report is a table: # | Proposed | Now | Why.
  Why: the user skipped reviewing an 11-item list; a side-by-side table is faster to scan.
