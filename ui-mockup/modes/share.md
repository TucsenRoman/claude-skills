# Share and other formats

- **Artifact:** publish options or a chosen direction as a shareable claude.ai page, for teammates or for viewing on a phone. Good when the user will come back to it or pass it on.
- **Inline visual:** a diagram, chart, or small interactive widget shown right in the chat (the visualize tool), for flows, structure, or comparisons that don't need a real render.
- **Figma:** `figma:figma-generate-design` when the user wants the result in Figma.
- **Files:** SVG for icons and diagrams; PDF for print or handoff; a plain HTML file when the user wants to keep or open the mock themselves.
