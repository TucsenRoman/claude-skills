# Copy lab

The real screen with its strings editable in place, so wording is judged where it lives, at real width. Used by `ui-copy`.

- **Edit in place:** click any string to edit it; every state of the screen (empty, loading, error, success) reachable from a switch.
- **Glossary check:** underline words the project's glossary rules out, and show the preferred term on hover.
- **Fit check:** narrowest supported phone width by default; outline text that wraps badly, truncates, or overflows.
- **A/B wording:** two versions of the same string or screen side by side.
- **Output:** a table of changed strings (# | Proposed | Now | Why) to paste back.
- Serve it over HTTP like the playground.
